# Project003-CalendarReminder

一个适合新手继续扩展的手机端日历提醒小应用。

## 已实现

- 记录农历生日，并自动找出下一次对应的公历日期。
- 记录公历重要事项。
- 保存备注和提前提醒天数。
- 首页显示最近事件，以及距离今天还有多少天。
- 数据保存在当前浏览器本地。
- 支持 PWA 安装到桌面。
- 支持浏览器系统通知：开启权限后，应用打开时会检查到期提醒并弹出通知。
- 支持 Supabase 邮箱登录和云同步，换手机后可同步提醒数据。
- 已加入 Vercel 静态部署配置。

## 使用方法

本地普通使用：直接用浏览器打开 `index.html`。

如果要测试 PWA 安装和系统通知，不能用双击文件的方式打开。请在项目目录运行：

```powershell
python -m http.server 5173
```

然后在浏览器打开：

```text
http://localhost:5173
```

手机添加到桌面需要用手机能访问的地址。正式使用时，推荐部署到 HTTPS 网站后，在手机浏览器菜单里选择“添加到主屏幕”。

## 云同步设置

1. 打开 Supabase，新建一个项目。
2. 进入 SQL Editor，执行 `supabase-schema.sql` 里的全部 SQL。
3. 在 Supabase 项目设置里找到 Project URL 和 Publishable key。旧版页面里可能叫 anon public key。
4. 打开本应用的“管理”页面，在“云同步”里填入 URL、发布密钥和邮箱。
5. 点击“发送登录邮件”，打开邮箱里的登录链接。
6. 回到应用，点击“立即同步”。

当前项目已经内置了刚创建好的 Supabase 配置。实际操作时也可以直接点击“使用已创建的 Supabase 项目”，然后只填写邮箱。

云同步使用 Supabase 登录账号隔离数据。没有登录时，应用仍会继续使用本地保存的数据。

## Vercel 部署

把本项目文件夹导入 Vercel 后，保持默认静态项目设置即可。

如果使用 Vercel CLI，可以在项目目录运行：

```powershell
vercel
vercel --prod
```

部署完成后，用 Vercel 给出的 HTTPS 地址打开应用，再在手机浏览器里添加到主屏幕。
